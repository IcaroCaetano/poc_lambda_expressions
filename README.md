# poc-lambda-expression

## Objective

To demonstrate how Lambda Expressions, introduced in Java 8, simplify code writing by enabling functional programming, reducing the boilerplate generated by anonymous classes, and making the code more readable and expressive.

Fluxo simplificado:

````plantuml
Código Java
        │
        ▼
Compilador javac
        │
        ▼
Bytecode com invokedynamic
        │
        ▼
JVM
        │
        ▼
LambdaMetafactory
        │
        ▼
Objeto que implementa a interface funcional
````
